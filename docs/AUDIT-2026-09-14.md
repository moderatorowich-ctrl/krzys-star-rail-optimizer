# Correctness audit — 2026-09-14

Release 1.1.1 fixes issues found in the website, local live import and visible-screen scanner.

- Pull planning now honors zero pulls and bounds pity for each banner, preventing invalid-input calculation failures.
- The all-relic filter exposes the entire inventory, not only its first 18 records. The aggregate score is correctly labeled an average.
- Removing characters or relics through live reconciliation clears dangling equipment and reservation references without mutating the previous account used for undo.
- Live snapshots reject conflicting envelope/account game versions. Reconnecting resets revision deduplication; unsuccessful merges do not consume a revision.
- OCR handles repeated flat/percentage stat labels and comma-separated values. Lower-level characters and cones no longer receive level-80 catalog base stats; those stats require review/correction.
- Warp scans preserve fields from earlier pages and can reset a guarantee to false.
- Fast capture checks stop before navigation; completed OCR waits through pause rather than being discarded.
- Non-object bridge messages are rejected safely.

Regression checks cover the fixes above where test fixtures are available. Browser tests cover desktop/mobile navigation, optimization, accessibility, imports and pairing with the real local bridge. This is not a live-game scanner certification: real inventory traversal and every game UI layout still require game-side testing.
